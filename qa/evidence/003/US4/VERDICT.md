### Findings

1. **blocking** — Notification items fail the axe scan (WCAG 2.5.3 Label in Name) on `/notifications` and in the bell popover, light and dark.
   - Observed: `a11y light/dark: /notifications passes axe` and `a11y light/dark: bell popover open passes axe` fail with `label-content-name-mismatch` "Elements must have their visible text as part of their accessible name", impact `serious`, on the item buttons (e.g. `button[aria-label="Unread: QA yesterday 1"]`, `.bg-primary-soft/30` in the popover with only the real alert). `/settings/notifications` passes both themes.
   - Expected: spec Accessibility *(gap)* — "no serious/critical violations in both themes" on `/notifications`.
   - Where: `apps/web/src/features/notifications/NotificationItem.tsx` — the `<button aria-label={`${n.read ? '' : 'Unread: '}${n.title}`}>` replaces the button's content-derived name, so the visible body, time and delivery text are not part of the accessible name. Remove the `aria-label` (or use an sr-only "Unread" span inside the button so the name still contains the visible text).
2. **minor** — The spec writes the Unread filter as `?unread=1`; the page's filter uses `?tab=unread` and `/notifications?unread=1` renders the All list (25 items). The API honours `unread=1` (3 items). Either document `?tab=unread` in the spec or accept `unread=1` in the page.
3. **observation** — The delivery chip's visible text is only "not sent" / "delivered" with an icon (the word "Email"/"WhatsApp" is only in the aria-label and tooltip). Spec wording is "Email not sent"; the accessible name matches.
4. **observation** — Red "Closes" colour for bids closing in < 3 days, "Email delivered" (`sent`), provider-failure `failed`, WhatsApp template params and the retry/back-off path are not observable in this E2E (log mailer, no WhatsApp capture, fixed provider URLs); they are covered by the API tests listed above. The "held before 08:00 IST" branch needs a clock before 08:00 IST (run was at 13 IST).

- Scheduled (cron) dispatch; only manual-sync dispatch was exercised end-to-end.
