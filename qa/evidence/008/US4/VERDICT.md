   - Where: `packages/db/src/schema.ts` (`tenders_open_state_idx`), `apps/api/test/perf-indexes.test.ts` (`['/tenders?state=Maharashtra', null]`). Related to review follow-up N7 (#521).
2. **major** — Feed p95 < 300 ms at concurrency 10 on 500k tenders is not reliably met on this shared 4-core host (max 358.6 ms, 8 of 22 samples over). It is Node-side queueing (sequential p95 ~60 ms, SQL < 1 ms). Either show a quiet-runner/CI measurement, or relax/clarify the criterion's environment.
   - Where: `scripts/load/feed.sh`, `apps/api/src/routes/tenders.ts` (5 queries per feed request: page, count, 3 facets).
3. **minor** — `scripts/load/feed.sh` uses a single cookie for 800 requests and exceeds `api.user` (600/min) on fast hosts → 200 × 429 on the last variant, reported as FAIL. Use one signup per variant.
4. **observation** — the `scanned_document` message uses a typographic apostrophe ("OCR’d") while the spec has a straight one.
5. **observation** — the feed DTO still carries `items` (tender line items, 35 keys). It is in `tenderListColumns`, so within the criterion, but worth confirming the cards need it.
6. **observation** — one full API run had 1 failing test (not captured) that did not reproduce in two later full runs; likely a timing test under host load. Worth watching.
